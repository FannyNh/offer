# Copilot Skills Structure

This folder contains reusable project Copilot skills.

## Available Skills

- `frontend-copilot/`: frontend implementation rules, context, and testing guidance for `offer-frontend/`.
- `backend-copilot/`: backend implementation rules, Java clean code guidance, and DDD-oriented architecture rules for `offer-backend/`.

## Skill Layout

Each skill should follow this layout:

- `SKILL.md`: entrypoint instructions and workflow.
- `references/`: focused rule files loaded as needed.
